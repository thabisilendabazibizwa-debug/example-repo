# Inventory Management System

1-This project is a simple Python inventory management system for a manager shoe stock in a store.

2- Features

- This system stores  information such as country, code, product, cost, and quantity of all shoes in the store.
- Displays inventory items.
- Calculates the cost of each shoe 
- This system keeps track of stock levels and manages inventory.

3- Tools Used for this build
 
- Python
- Object-Oriented Programming (OOP)
